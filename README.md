## 🧬 About Me

I'm a **Biotechnology student** specializing in the intersection of **biology and computation**. My work focuses on applying Machine Learning and Bioinformatics pipelines to extract actionable insights from complex biological datasets.

**What I do:**

- 🔬 Build ML models for genomic/proteomic data analysis
- 🐍 Develop Python-based bioinformatics workflows
- 📊 Translate biological questions into computational solutions
- 📚 Bridge the gap between wet-lab research and data science
